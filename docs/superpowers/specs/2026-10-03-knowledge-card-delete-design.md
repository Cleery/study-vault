# 知识卡片删除设计

## 目标与范围

为单人使用的知识卡片增加删除入口。删除卡片后，其关联题目和其他知识卡片继续保留，相关多对多关系解除。当前版本不增加回收站、批量删除或自动清理未使用科目。

## 用户流程

在知识卡片详情页显示“删除卡片”入口。点击后进入独立确认页，显示卡片名称、关联题目数量、以前置关系关联的卡片数量，并说明题目和其他卡片会保留。用户可以返回详情页取消。只有点击确认页的删除按钮并提交 POST 请求时，才执行删除。成功后返回知识卡片列表并显示结果提示。

## 代码边界

新增知识卡片删除 URL、视图及确认模板，详情页添加入口。视图在 GET 时只读取卡片，在 POST 时使用数据库事务删除该卡片。Django 的关联表外键级联处理解除其与题目及其他卡片的关系。删除不存在的卡片返回 404。沿用现有站点的访问保护和 CSRF 机制。

## 验证

测试 GET 不删除、确认页面信息、POST 删除与跳转、关联题目和其他卡片保留且关系解除、缺失卡片返回 404，以及 CSRF 保护。运行完整测试与 Django 检查。此项先实现并在本地验证；服务器发布另行执行。
