# 待复习、标签与统计页面工作台设计

日期：2026-10-02

## 目标与范围

将现有“待复习”“标签”“统计”三个页面统一为简洁的分区工作台。保留现有数据模型、复习规则、标签操作和统计口径。本次只调整页面呈现及支持这些页面所需的查询参数和上下文，不增加图表、自动复习决策或新的标签层级规则。

## 已确认的页面方向

用户选择分区工作台方案。标签页采用左侧分类、右侧标签内容；标签的常用操作直接显示，归档和合并收进“更多操作”。待复习页突出三个队列。统计页显示四个数字卡片，以及科目和掌握程度汇总。

## 共享视觉规则

沿用现有青绿色、米白色和圆角卡片。页面标题、主要操作和当前状态形成清晰层级。桌面端使用分区布局，窄屏按阅读顺序堆叠，不让侧栏遮挡内容。链接和按钮保留键盘焦点样式，所有筛选控件有可见标签。空状态提供对应的下一步入口。

## 待复习页

顶部显示“今日到期”“最近错误”“逾期”三个队列入口及各自题数。当前队列有明显选中状态。知识卡片筛选位于队列入口附近，切换队列时保留已选知识卡片，清除筛选后回到当前队列的全部题目。

下方按当前队列展示题目卡片，每张卡片显示标题、科目、下次复习时间，以及“开始复习”按钮。按钮继续进入现有复习详情页，保存复习结果的行为不变。空队列显示明确的提示和返回题目检索的入口。无 JavaScript 时队列链接、筛选表单和复习入口仍可使用。

队列结果和计数继续复用当前视图中的三个查询函数。默认队列保持“今日到期”。无效队列值回退到默认队列，并让页面状态与实际结果一致。

## 标签管理页

顶部提供标签名称搜索和“新建标签”入口。桌面端左侧按现有 `Tag.kind` 分类，包含“全部标签”；右侧显示当前分类和搜索条件下的标签列表。分类与搜索通过 GET 参数表达，刷新和复制链接后仍保持状态。默认只显示未归档标签，提供查看已归档标签的明确入口。标签数量较少时保留完整内容，不强制分页；实现时需避免每行重复生成全部合并目标选项。

点击某个标签后，在右侧显示它的详情与编辑表单。常用操作“编辑”直接可见；“归档”和“合并”放入“更多操作”区域。新建时同一区域显示名称、类型和可选父级。父级字段保留原有约束，页面以简短说明提示其用途。选中标签以 `selected` 查询参数表示；现有编辑 URL 继续可用，并将同一个标签设为选中状态。

归档与合并继续通过 POST 执行，并使用服务端校验。点击“归档”或“合并”时先通过 GET 打开站内确认页，清楚展示来源标签以及合并目标；确认页的表单再 POST 到现有执行路由。合并目标初始为空，用户必须主动选择，服务端拒绝空目标。确认页提供取消链接，返回原分类、搜索、已归档状态及选中标签。无 JavaScript 时也走相同确认流程。失败时在确认页显示服务端错误信息，保留已选目标和可重新提交的表单。已归档标签仍可在历史题目中显示，但不作为新建题目时的默认候选。新建、编辑、归档、合并不改变现有标签关系语义。

分类、搜索、是否查看归档标签及选中标签都通过 GET 参数保持。新建或编辑验证失败时直接返回同一工作台，保留表单输入、当前分类与搜索、选中标签，并显示字段错误。成功保存、归档或合并后重定向回对应分类及搜索结果；若原标签已归档或被合并，清除原选中状态并显示操作结果消息。直接访问无效的选中标签 ID 时显示列表默认状态，不执行写入。

窄屏时分类区域移到列表上方，详情与操作区域接在列表之后。交互应有无 JavaScript 的可用路径；增强脚本只用于切换详情、确认和局部体验，不承担唯一的数据提交路径。

## 统计页

顶部四个数字卡片依次显示题目总数、待复习题数、近 30 天复习次数、近 30 天错误次数。下方两块汇总区域显示各科目题数和各掌握程度题数。数据继续来自现有 `get_statistics()`，不修改过滤范围、日期计算或掌握程度含义。

掌握程度的分组标题使用 `Question.MASTERY_CHOICES` 中的中文显示名称，数值使用现有统计结果中的机器键查找。没有题目或记录时，数字卡片显示 0，分组区域显示“暂无数据”或对应零值说明。第一版不加入图表和趋势计算。

## 技术边界与验证

复习、标签和统计分别保留在现有模板与视图中。页面专属 CSS 可放在单独静态文件，避免继续扩大共享样式文件。标签筛选和选中详情所需的查询逻辑应与写入操作分开，保证归档、合并后刷新状态准确。模板中对用户输入保持默认转义，禁止把未清理的标签名称写入 HTML 属性或脚本。

测试覆盖：三个队列的选中状态和筛选保留；复习卡片到详情页的入口；标签分类、搜索、选中、已归档显示；合并没有默认目标且错误可见；统计数字与现有统计函数一致；窄屏布局对应的样式契约。运行完整 Django 测试、系统检查、迁移检查和静态文件检查。若浏览器自动化依赖缺失，需明确标记未执行的项目，再用本机页面做手动核对。
